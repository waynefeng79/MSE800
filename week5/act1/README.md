# Conditional exchange scenario

## In this scenario, user may place a conditional exchange order which includes an exchange rate and a date in future.
- When the real exchange rate reaches the set one before the deadline, exchange will be executed automatically.
- If the real exchange rate doesn't reach the set one before the deadline, the scheduled exchange order will be cancelled.
- The result of successful or failed order will be notified to the user

## The application should provide two options when user tends to exchange money
- Real time exchange with current rate on market
- Conditional exchange as described above
